# 第1回：スクレイピング入門【解答・解説】

## 📝 問題1の解答

```
User-agent: Googlebot
Allow: /

User-agent: *
Disallow: /admin/
Disallow: /api/
Crawl-delay: 3
```

---

### Q1. `/public/page.html` を見ていい？

**答え: ✅ 見ていい**

### なぜ？

```
考え方の手順:

1. 自分のプログラムは Googlebot じゃない
   → だから「User-agent: *」のルールを見る

2. 「User-agent: *」の Disallow を確認
   → /admin/ と /api/ だけ禁止されてる

3. /public/ は禁止リストにない
   → 禁止されてない = OK！
```

---

### Q2. `/admin/users.html` を見ていい？

**答え: ❌ 見ちゃダメ**

### なぜ？

```
考え方の手順:

1. 「User-agent: *」の Disallow を確認
   → Disallow: /admin/ と書いてある

2. /admin/users.html は /admin/ の中にある
   → /admin/ で始まるURLは全部ダメ

3. だから見ちゃダメ
```

---

### Q3. 何秒待つべき？

**答え: 3秒以上**

### なぜ？

```
Crawl-delay: 3 と書いてある
→ 「3秒は待ってね」という意味
→ 余裕を持って 3〜5秒待つのがマナー
```

いろんなページが `Disallow` されてる。検索エンジンの裏側は見せたくないから。

### GitHub の robots.txt を見ると…

比較的シンプル。でも `/api/` とかは制限されてることが多い。

## 📝 問題3の解答

### シナリオA: ニュースの見出しを毎日1回

**答え: ⚠️ 条件付きでOK**

```
考え方:

✅ robots.txt は OK
✅ 毎日1回 = サーバーに優しい
✅ 見出しだけ = 著作権的にセーフなことが多い

でも…
⚠️ 利用規約も確認しよう
⚠️ 商用利用はダメな場合が多い
```

### シナリオB: SNSの投稿を全部コピー

**答え: ❌ ダメ**

```
考え方:

❌ 「全部コピー」= 著作権侵害
❌ SNSは利用規約でスクレイピング禁止が多い
❌ 公開したら訴えられる可能性も
```

### シナリオC: ECサイトから商品価格を1時間に1回

**答え: ⚠️ 条件付きでOK**

```
考え方:

✅ robots.txt は OK
✅ 1時間に1回 = サーバーに優しい
✅ 個人的な分析目的 = 問題ない

でも…
⚠️ データの商用利用はダメな場合が多い
⚠️ データを公開するのも別途確認が必要
```

## 💡 今回のポイントまとめ

### 覚えておくこと3つ

| ポイント | 内容 |
|---------|------|
| ① | robots.txt は「お願い」。でも必ず守る |
| ② | アクセスは1〜3秒空ける。急いでもダメ |
| ③ | 迷ったらやらない。公式APIを探す |

### robots.txt の読み方

```
User-agent: *     ← 「みんなに対して」
Disallow: /admin/ ← 「/admin/ は見ないで」
Crawl-delay: 5    ← 「5秒待ってね」
```

### これだけは絶対ダメ！

1. 短時間に大量アクセス
2. ログインが必要なページに勝手に入る
3. 集めたデータを勝手に公開
