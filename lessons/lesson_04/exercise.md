## 解説

### 関数とは

関数は、よく使う処理をまとめて名前をつけたものです。

関数を使わない場合:

```python
print("こんにちは、田中さん")
print("こんにちは、佐藤さん")
print("こんにちは、鈴木さん")
```

関数を使う場合:

```python
def greet(name):
    print(f"こんにちは、{name}さん")

greet("田中")
greet("佐藤")
greet("鈴木")
```

関数を使うと、処理の内容を変更したいときに1箇所を直すだけで済みます。

関数を使わない場合と使う場合を比較すると、実行部分のコードの可読性が上がり、分量も減ってスッキリしています。さらに例えば、「こんにちは」から「こんばんは」に変えたいとき、関数を定義した部分を1箇所だけ修正すれば、出力されるすべての挨拶が変更されます。

### 関数の定義

では、関数を実際に自分で設定する（定義する）方法について説明します。関数は `def` を用いて以下のように定義します。
```python
def 関数名(引数):
    処理
    return 戻り値

# 例：2つの数を足す関数
def add(a, b):
    result = a + b
    return result

# 使い方
answer = add(3, 5)
print(answer)  # 8
```

具体例の中には、`def` だけでなく `return` などが登場しました。関数に関する用語を整理しておきましょう。

用語の説明:

| 用語 | 意味 | 例 |
|------|------|-----|
| def | 関数を定義するキーワード | `def greet():` |
| 引数 | 関数に渡すデータ | `greet("田中")` の "田中" |
| return | 結果を返す | `return result` |
| 戻り値 | 関数から返ってくる値 | `add(3, 5)` の結果 `8` |

### ファイルの読み書き

次に、ファイルの読み書きについて説明します。まずは具体例を見てもらいましょう。

書き込み:

```python
with open("test.txt", "w", encoding="utf-8") as f:
    f.write("1行目\n")
    f.write("2行目\n")
```

読み込み:

```python
with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
```

これらにより、ファイルへの読み書きができるようになります。上のプログラムを実行すれば、同一のフォルダ内に `test.txt` が作成され、`f.write` によって記述された内容が書き込まれていることが分かります。また、両者のコードを見比べると `"w"` と `"r"` の部分が異なりますが、それぞれ `"w"` → write（書き込む）、`"r"` → read（読み込む）を意味しています。`utf-8` については後ほど触れます。

`with` を使うと、ファイルを自動で閉じてくれます。ファイル操作では必ず `with` を使うようにしてください。

### エラー処理（try-except）

以下のコードは、エラーが起きてもプログラムを止めないようにする仕組みです。

```python
try:
    result = 10 / 0  # 0で割るとエラー
except ZeroDivisionError:
    print("エラーが起きました")
```

以下はPythonでよくあるエラーです。

よくあるエラー:

| エラー名 | 発生条件 |
|---------|----------|
| ZeroDivisionError | 0で割った |
| FileNotFoundError | ファイルがない |
| KeyError | 辞書にないキーにアクセス |
| IndexError | リストの範囲外にアクセス |

### 4.6 問題4：安全な割り算

0で割ってもエラーにならない関数を作ってください。

```python
def safe_divide(a, b):
    # ここを書く
    # 0で割ったら None を返す
    pass

# テスト
print(safe_divide(10, 2))   # 5.0
print(safe_divide(10, 0))   # None
```

**考え方:**

この解答は大きく分けて2つの方法があります。

**方法A:** if文で事前にチェック
- bが0かどうかを先にチェック
- 0なら None を返す
- そうでなければ計算結果を返す

**方法B:** try-exceptでエラーをキャッチ
- 0で割ったときに ZeroDivisionError が発生することを利用
- except で該当エラーだけをキャッチ

> まずは方法Aで実装してみて、余裕があれば方法Bにも挑戦してみましょう。(後のレッスンでより詳しく解説します)

## 困ったときは

### 「returnを忘れた」

関数が `None` を返す場合、`return` を書き忘れている可能性があります。

```python
# 誤り
def add(a, b):
    result = a + b
    # return がない

# 正しい
def add(a, b):
    result = a + b
    return result
```

### 「ファイルが見つからない」

ファイルのパス（場所）が間違っている可能性があります。同じフォルダにいるか確認してください。

### 「encoding とは」

文字化けを防ぐための指定です。日本語を使う場合は `encoding="utf-8"` を付けてください。
