## ハンズオン：リストと辞書を作ってみよう

以下のコードをファイルに保存して実行してください。

```python
# リストを作る
fruits = ["りんご", "バナナ", "みかん"]
print(fruits)
print(fruits[0])  # 最初の要素

# 辞書を作る
person = {

    "age": 25,
    "city": "東京"

```

実行すると、リストの内容と辞書の内容が表示されます。リストは番号で、辞書は名前でデータを取り出せることを確認してください。

### Pythonの特徴（他の言語との違い）

| 特徴       | Python             | JavaScript | Java  |
| ---------- | ------------------ | ---------- | ----- |
| 文の終わり | なし               | `;`        | `;`   |
| ブロック   | インデント（空白） | `{ }`      | `{ }` |

Pythonでは、インデント（行頭の空白）がプログラムの構造を決定します。

```python
if True:
    print("これはifの中")    # 4つのスペース
    print("ここもifの中")    # 4つのスペース
print("これはifの外")        # スペースなし
```

インデントがずれているとエラーになります。

### print()関数

`print()` はカッコの中に書いたものを画面に表示する関数です。プログラムが「今どんな状態になっているか」を確認するために使います。JavaScript の `console.log()` と同じ役割です。

```python
name = "田中太郎"
print(name)         # 田中太郎
print("こんにちは")  # こんにちは
print(1 + 2)        # 3
```

この授業では、コードを実行した結果を確認するためによく登場します。

name = "田中太郎"      # 文字列（str）

### リスト

リストは、順番に並んだデータの集まりです。買い物リストのようなものと考えてください。

```python
shopping = ["りんご", "バナナ", "牛乳"]

# インデックス（番号）でアクセス
print(shopping[0])   # りんご（0番目）
print(shopping[1])   # バナナ（1番目）
print(shopping[-1])  # 牛乳（後ろから1番目）
```

よく使う操作:

```python
fruits = ["apple", "banana"]

# 追加
fruits.append("cherry")
# 結果: ["apple", "banana", "cherry"]

# 削除
fruits.remove("banana")
# 結果: ["apple", "cherry"]

# 長さ
print(len(fruits))  # 2
```

### 辞書

Pythonでは、先ほど紹介したリストを進化させたような「辞書」と呼ばれるものがあります。リストでは数字で要素を取り出していましたが、辞書では**名前（キー）を指定して取り出す**ことができます。名前（キー）と値のペアで表され、現実世界でいうところの住所録のようなものです。

具体的な機能を理解するために、以下のプログラムを実行してみましょう。

```python
person = {
    "name": "田中太郎",
    "age": 25,
    "city": "東京"
}

# キーでアクセス
print(person["name"])  # 田中太郎
print(person["age"])   # 25
```

#### リストと辞書の違い

|            | リスト           | 辞書                 |
| ---------- | ---------------- | -------------------- |
| 書き方     | `[ ]`            | `{ }`                |
| 取り出し方 | 番号で           | 名前で               |
| いつ使う   | 順番が大事なとき | 名前で管理したいとき |
| 例         | 買い物リスト     | 人の情報             |

### 条件分岐（if文）

Scratch の「もし〜なら」や JavaScript の `if` と同じ概念です。条件によって処理を分けることができます。

```python
score = 75

if score >= 80:
    print("よくできました")
elif score >= 60:
    print("まあまあです")
else:
    print("がんばりましょう")
```

#### ループ（for文）

```python
fruits = ["apple", "banana", "cherry"]

for fruit in fruits:
    print(fruit)
```

リストの中身を1つずつ取り出して処理します。

## 困ったときは

### 「リストと辞書、どちらを使えばいい？」

番号で取り出すならリスト、名前で取り出すなら辞書です。

### 「辞書のリスト？リストの辞書？」

複数の人のデータを考えます。「人」が複数あるのでリスト、各人には「名前」「年齢」があるので辞書。したがって「辞書のリスト」になります。

```python
people = [{"name": "A", "age": 20}, {"name": "B", "age": 25}]
```

### 「IndentationError と言われる」

インデント（スペース）がおかしいです。4つのスペースで統一してください。Tabとスペースを混ぜないように注意してください。
