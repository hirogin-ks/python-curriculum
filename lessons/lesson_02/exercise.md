## 導入：プログラムを動かすための準備

前回、スクレイピングとは何かを学びました。では、実際にスクレイピングのプログラムを動かすには何が必要でしょうか。

料理にたとえると、レシピ（＝プログラムのコード）があるだけでは、実際に料理を作ることはできません。
そのレシピを実行するためのキッチン（＝実行環境）があってはじめて、調理ができるようになります。

さらに、包丁やまな板、鍋やフライパンといった調理器具（＝ライブラリ）がそろっていなければ、レシピ通りに効率よく、あるいは正確に料理を仕上げることはできません。

つまり、

- レシピ ＝ 何をどう作るかを書いた手順（コード）
- キッチン ＝ 料理を実際に行う場所や設備（実行環境）
- 調理器具 ＝ 作業を助ける道具（ライブラリ）

がそろって、はじめて「料理（＝プログラムの実行）」が完成するのです。

今回は、この料理の例えで言うところの、キッチンつまり実行を行うための場所を整える作業を行います。

## 解説

### ライブラリとは何か

ライブラリとは、「よく使う機能をまとめたプログラムの部品集」です。

プログラミングでは、同じような処理を何度も書くことがあります。例えば「Webページを取得する」「HTMLを解析する」「CSVファイルを作成する」といった処理です。これらの処理を毎回ゼロから書くと、単に面倒なだけでなく、コードにバグが入り込む可能性も高くなります。

こうした問題を解決するために、プログラマーはよく使う処理を「関数」としてまとめるという工夫をします。さらに、そのような関数をひとつのパッケージにまとめたものが「ライブラリ」です。世界中の優秀なプログラマーたちが作成したライブラリは無料で公開されており、私たちもそれを活用することで、複雑な処理を簡単に実現できます。

#### 具体例

スクレイピングでよく使うライブラリを紹介します。

| ライブラリ名  | 役割                                       |
| ------------- | ------------------------------------------ |
| requests      | WebページのHTMLを取得する                  |
| BeautifulSoup | HTMLを解析して、必要なデータを取り出す     |
| Selenium      | JavaScriptで動的に生成されるページを扱う   |
| pandas        | データを表形式で扱い、CSVやExcelに出力する |

これらのライブラリを使うことで、数行のコードでWebページを取得し、データを抽出し、ファイルに保存するといった処理が実現できます。

#### なぜライブラリを使うのか

1. **時間の節約**: 一から作るより圧倒的に早い
2. **品質の向上**: 多くの人に使われ、テストされているため、概ねバグはないものと見なして良い
3. **保守性**: ライブラリが更新されれば、セキュリティ修正なども自動的に適用できる

### 仮想環境とは何か

Pythonでは、プロジェクトごとに「仮想環境」を作成することが推奨されています。

#### なぜ仮想環境が必要なのか

複数のプロジェクトを同時に進めていると、以下のような問題が発生することがあります。

- プロジェクトAでは `requests` のバージョン2.25を使いたい
- プロジェクトBでは `requests` のバージョン2.28を使いたい

同じパソコンに1つのPython環境しかないと、これらを同時に満たすことができません。古いバージョンを使っているプロジェクトが動かなくなったり、新しいバージョンに依存している機能が使えなかったりします。

仮想環境を使えば、プロジェクトごとに独立した環境を作成できます。

```
あなたのパソコン
├── プロジェクトA/
│   └── .venv/        ← プロジェクトA専用の環境
│       └── requests 2.25
│
└── プロジェクトB/
    └── .venv/        ← プロジェクトB専用の環境
        └── requests 2.28
```

#### 仮想環境のメリット

1. **依存関係の分離**: プロジェクトごとに異なるバージョンのライブラリを使える
2. **クリーンな状態の維持**: システム全体のPython環境を汚さない（ライブラリのバージョンの衝突など、プロジェクト間の干渉が起こりにくい）
3. **再現性**: 他の人が同じ環境を再現しやすい

## Pythonのインストール

Pythonがインストールされていない場合、または古いバージョンの場合は、以下の手順でインストールしてください。

https://kinsta.com/jp/blog/install-python/ を参考にしてください。
下にも手順を載せていますがおおまかな流れなので、詳細は上記リンクを参照してください。

### Windowsの場合

1. https://www.python.org/downloads/windows/ にアクセスする
2. 「Download Python 3.x.x」ボタンをクリックする
3. ダウンロードしたインストーラーを実行する
4. **重要**: 最初の画面で「Add Python to PATH」にチェックを入れる
5. 「Install Now」をクリックする

「Add Python to PATH」にチェックを入れ忘れると、ターミナルからPythonを実行できなくなります。忘れた場合は、再インストールしてください。

### Macの場合

✳︎ Macでは最初からpythonがインストールされていることがあります。 最新版でない場合やインストールされていない場合は、以下の方法でインストールしてください。

#### 方法1：公式サイトから（初心者向け）

1. https://www.python.org/downloads/ にアクセスする
2. 「Download Python 3.x.x」ボタンをクリックする
3. ダウンロードした `.pkg` ファイルを開いてインストールする

#### 方法2：Homebrewを使う（推奨）

ターミナルで以下のコマンドを実行します。

```bash
brew install python
```

Homebrewがインストールされていない場合は、先にHomebrewをインストールしてください。「Homebrew インストール Mac」で検索すると手順が見つかります。

## 仮想環境の作成

以下はあくまでも例なのです。実際のプロジェクトのフォルダ構成は異なる場合があります。
自身のプロジェクトのフォルダ構成に合わせて読み替えてください。

- プロジェクトのフォルダがない場合は、事前に作成しておいてください。

- プロジェクトのPathがわからない場合は，ターミナル（WindowsはPowerShell）で`pwd`コマンドを実行すると確認できます。

### Step 1：作業フォルダに移動する

ターミナル（WindowsはPowerShell）で、プロジェクトのフォルダに移動します。

```bash
# Windows
cd C:\Users\あなたの名前\Documents\python-scraping-course

# Mac
cd ~/Documents/python-scraping-course
```

- `cd` は "change directory"（ディレクトリを移動する）の略です。

### Step 2：仮想環境を作成する

以下のコマンドを実行します。

```bash
python -m venv .venv
```

Macで `python` コマンドが見つからない場合は、`python3` を使ってください。

```bash
python3 -m venv .venv
```

このコマンドを実行すると、`.venv` という名前のフォルダが作成されます。この中に、このプロジェクト専用のPython環境が入っています。

### Step 3：仮想環境を有効にする

作成した仮想環境を「有効」にする必要があります。有効にすると、インストールしたライブラリがこの環境にのみ適用されます。

**Windowsの場合（PowerShell）:**

```powershell
.\.venv\Scripts\Activate.ps1
```

**Macの場合:**

```bash
source .venv/bin/activate (または，. ./.venv/bin/activate)
```

### 成功の確認

仮想環境が有効になると、プロンプトの先頭に `(.venv)` と表示されます。

注意：ターミナルの種類によって表示が異なる場合があります。

```
(.venv) PS C:\Users\...>         # Windows
(.venv) user@mac ~ $             # Mac
```

この `(.venv)` が表示されている間は、この仮想環境が有効になっています。

### 仮想環境を終了する

作業が終わったら、以下のコマンドで仮想環境を終了できます。

```bash
deactivate
```

`(.venv)` の表示が消えたら、仮想環境が終了しています。

## ライブラリのインストール

仮想環境が有効な状態で（`(.venv)` が表示されている状態で）、以下のコマンドを実行します。

```bash
pip install -r requirements.txt
```

このコマンドは、`requirements.txt` というファイルに書かれているライブラリを一括でインストールします。

インストールには数分かかることがあります。進捗状況が表示されるので、完了するまで待ちましょう。

### インストールされたライブラリの確認

```bash
pip list
```

このコマンドで、インストールされているライブラリの一覧が表示されます。`requests`、`beautifulsoup4`、`selenium`、`pandas` などが表示されていれば成功です。

## よくあるエラーと対処法

環境構築では、様々なエラーに遭遇することがあります。エラーメッセージは英語で表示されることが多いですが、落ち着いて読めば対処できます。

### 「python が見つかりません」「python は認識されていません」

**原因**: Pythonがインストールされていないか、PATHが通っていません。

**対処法**:

- Windowsの場合：Pythonを再インストールし、「Add Python to PATH」にチェックを入れる
- Macの場合：`python3` コマンドを試す

### 「スクリプトの実行がシステムで無効になっています」（Windows）

**原因**: PowerShellの実行ポリシーが制限されています。

**対処法**: PowerShellを管理者として開き、以下を実行します。

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

「実行ポリシーを変更しますか？」と聞かれたら「Y」と入力してEnterを押します。

### 「pip install でエラーが出る」

**原因**: pipが古いか、ネットワークの問題が考えられます。

**対処法**: まずpipを更新してみてください。

```bash
pip install --upgrade pip
```

その後、再度インストールを試みます。

```bash
pip install -r requirements.txt
```

### 「Permission denied」「アクセスが拒否されました」

**原因**: 仮想環境ではなく、システム全体のPythonにインストールしようとしている可能性があります。

**対処法**: 仮想環境が有効になっているか確認してください。プロンプトの先頭に `(.venv)` が表示されているはずです。表示されていなければ、仮想環境を有効にしてから再実行してください。

### エラーメッセージの読み方

英語のエラーメッセージが出ても慌てないでください。以下の手順で対処できることが多いです。

1. エラーメッセージを最後まで読む（最後の数行に原因が書かれていることが多い）
2. エラーメッセージをそのままコピーして検索する
3. 「Python」と組み合わせて検索する（例：`ModuleNotFoundError: No module named 'requests' Python`）

多くの場合、同じエラーに遭遇した人がいて、解決方法が見つかります。
